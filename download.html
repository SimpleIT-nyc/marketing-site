Before you install

  • PHP 8.2 or newer, with extensions: pdo_mysql, mbstring, openssl, tokenizer, ctype, json, fileinfo, curl, and imap (only required if you want automatic email-to-ticket intake).
  • A MySQL or MariaDB database, and a database user with privileges to create tables (and CREATE if you want the installer to create the database itself).
  • A web server (Apache, Nginx, or LiteSpeed) able to point its document root at the package's public/ folder.
  • An SSL certificate is strongly recommended for any real deployment. See the installation guides for platform-specific notes.
